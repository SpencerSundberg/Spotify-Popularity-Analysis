Before the charts

How to read the popularity score

A score from 0 to 100Spotify gives every track a number, and higher means more popular. It is a relative score, not a count of streams.
Mostly recent playsThe score leans on how often a track has been played and how recently, so songs people are listening to now tend to beat songs that were big in the past.

By release year

Newer songs score higher

Popularity follows recent listening, so 2019 songs get a built-in boost. That is a recency effect, not a sign that music is getting better.

Method and limits

How I did it

I loaded the public TidyTuesday Spotify dataset (32,833 track-in-playlist rows) into SQLite, built a one-row-per-track table, and wrote SQL to compare average popularity across playlist counts, genres, years, and song lengths. I computed correlations in Python. Every query is in analysis.sql.

SELECT CASE WHEN n_playlists >= 6 THEN 6 ELSE n_playlists END AS playlists,
       COUNT(*) AS tracks, ROUND(AVG(popularity), 1) AS avg_popularity
FROM tracks GROUP BY 1 ORDER BY 1;
Limits to keep in mind
  • These are associations, not causes: popular songs also get added to more playlists, so the effect runs both ways.
  • The dataset was collected by sampling playlists, so a song's playlist count is partly a result of how it was sampled.
  • Popularity is a Spotify score from 0 to 100 taken at one point in time (early 2020). of tracks score 0.
  • Streams, saves, and listener counts are not in this dataset, so I could not analyze them directly.
